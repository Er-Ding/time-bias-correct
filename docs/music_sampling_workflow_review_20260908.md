## 核心判断

你的流程是合理的，我支持把它作为下一版主流程。它的作用是保留每个谱峰附近的多种可能解释，再利用场景几何和共同的 bias 筛选出一致的位置。

改造前实现成“各次 CSI 扰动分别求解，再汇总结果”，偏离了你要求的“先汇集候选、先聚类、再联合求解”。旧主流程把原始谱峰直接送入第一次候选生成和聚类，扰动样本另行求解；新版已改为全部谱面样本先进入候选生成和聚类。

本次改造的流程选择已经明确：采用 MUSIC 谱附近采样，移除定位主流程中的“观测 CSI 再加噪、重复提峰、峰配对、逐次求解、结果平均”这条支路。CSI 扰动不作为新主流程的前置步骤或失败回退。

此前文档讨论“不能因为网格重复就否定所有 CSI 扰动方法”，是在评价方法适用范围，并不构成继续使用它的理由。把这段讨论放在流程决定中，造成了不必要的歧义；本版明确更正。

不过，候选点变多、点云变分散，并不能直接证明定位更准确。这套方法需要明确以下几个环节。

## 建议的主流程

1. 输入：接收到的一份带噪 CSI。
2. 计算二维 MUSIC 谱并寻找谱峰。
3. 在每个峰附近细化谱面，采样多组“角度、观测时延”。
4. 对每个样本执行反向射线追踪，保留候选位置随 bias 的变化关系。
5. 按来源谱峰与反射路径结构分组，汇集候选并进行第一次聚类。
6. 从每个簇选取代表候选。
7. 联合估计所有路径共同的 bias 与 UE 位置。
8. 检查预测路径与原始观测是否一致。

这里的输入始终是实际接收到的那份带噪 CSI。“原始观测”指这份接收数据，不是无噪声的 CSI。

## 1. 可以在 MUSIC 谱附近采样，但需要定义“怎么采”

MUSIC 谱反映的是候选参数与信号结构的匹配程度，其定义是“伪谱”。因此，我的判断是：可以根据谱形设计采样分布，但把谱值归一化，并不会自动得到真实角度、时延的概率分布。

参考：[MathWorks：MUSIC 原理与定义](https://www.mathworks.com/help/phased/ug/music-super-resolution-doa-estimation.html)。

第一版可以这样设计：

- 在每个谱峰周围确定有限的二维区域。
- 根据区域内的谱形分配样本，同时保留少量均匀采样，避免样本全部挤在最高点。
- 保留角度与时延的联合变化，不直接假设两者独立。
- 每个峰单独分配采样数量，避免强峰占走全部样本。

CSI 噪声服从高斯分布，不代表经过 MUSIC 提峰之后，角度和时延误差也必然是独立高斯分布。采样区域大小、谱值如何影响采样频率，都需要通过独立实验确定。

这里生成的是搜索候选。点云范围不能直接解释成具有某个覆盖概率的置信区间。

## 2. 网格问题在 MUSIC 谱上处理

当前提峰函数返回的是网格上的局部极大值。新流程用这些峰定位采样区域，再在区域内部生成不同的角度、时延候选，不再依靠观测 CSI 额外加噪后“跳到另一个网格”来产生候选。

不能仅在原来的几个网格点之间重复抽样。应该先在峰附近用 MUSIC 公式重新计算更细的谱面，或直接评估连续的角度、时延坐标。MUSIC 的搜索网格本身可以调整。

参考：[MathWorks：MUSIC 搜索网格说明](https://www.mathworks.com/help/phased/ref/musicdoa.html)。

这样能减轻网格取整的影响，但更细的计算本身不会增加观测信息。

## 3. bias 未知时，“初始候选点”需要保留它随 bias 的变化

这里必须保持：

```text
观测时延_k = 几何传播时延_k + b + 时延估计误差_k
```

其中，b 是各条路径共同的时钟偏差。

采样得到的是角度和包含 bias 的观测时延。因此，在反射路径固定的情况下，同一个样本通常对应一个随 b 移动的位置 p_k(b)，而不是一个已经确定的 UE 位置。

你可以选一个统一的参考 bias 来画初始点云，但后续必须保留候选的移动关系和有效 bias 范围。联合求解时，各条路径使用同一个 b；不能给每条路径各自一个自由的 bias，否则会丢失共同钟差带来的约束。

## 4. 第一次聚类需要压缩候选，同时保留物理含义

建议只在同一来源谱峰、同一反射路径结构内部聚类，并允许留下多个代表候选。

旧聚类检查两条候选轨迹在共同 bias 范围内能够达到的最小距离，即使只在某个 bias 附近接近也可能合并。新版已改为共同区间端点处的最大距离，并要求簇内成员两两满足阈值，避免仅因交点接近或连续串联而合并。

代表候选优先从簇内选一个真实、有效的成员。若使用平均位置或平均方向，需要重新检查它是否仍对应合法的直射或镜面反射路径。

另外，同一谱峰抽出的 100 个样本，是同一份观测的 100 种候选解释。不能把它们当成 100 条独立测量，也不能因为采样更多，就自动增加这条路径在求解中的权重。

## 5. 验证重点应该是候选覆盖和最终误差

建议在完全相同的带噪 CSI 上，比较以下三种候选生成方式：

- 单个谱峰候选。
- 局部细网格候选。
- 局部蒙特卡洛候选。

后两组控制相近的候选预算，使用相同的聚类和求解规则。这里仅有角度、时延两个采样维度，随机采样是否优于局部细网格，也应该由实验回答。

需要观察：

- 聚类前是否覆盖正确解，聚类后是否保留了它。
- 定位误差的中位数、P90、CDF，以及 bias 误差。
- 失败率、计算耗时，以及改变采样数量和随机种子后的稳定性。

真实位置、真实 bias 和真实路径只用于独立评估。若路径约束不足，或正确路径已经漏检，增加峰附近的采样数量也不保证能恢复正确位置。

因此，这次方法设计最需要先固定的是：采样区域与分布、候选随 bias 的表示、第一次聚类的合并规则。这三处明确后，你要求的中间点云和代表点才既能解释流程，也能真正参与最终定位。

## 6. 对应的代码改造清单

本节记录已经落实的改造清单。新运行使用谱面采样流程；旧参数会明确报错，旧实验只通过报告兼容分支读取，不会混入新的实验计划。

### 6.1 区分实验重复和算法内部采样

- 实验层：同一 UE 的固定信道加上独立高斯噪声，得到多份模拟接收数据。已约定的每个 UE 5 次重复可以保留，每一份接收数据单独定位、单独输出结果。
- 定位层：接收其中一份带噪 CSI，计算它的 MUSIC 谱。后续直接在谱峰附近采样，定位过程不再给这份 CSI 额外加噪。
- 采样层：每个峰抽取多组角度、观测时延。它们是同一份观测的候选解释，不是新的独立测量，也不是新的实验重复。

### 6.2 替换主流程中的函数调用

| 环节 | 当前实现 | 应改成的实现 |
| --- | --- | --- |
| MUSIC 计算 | 观测 CSI 一次，随后对多份额外加噪 CSI 重算 | 只处理这一份观测 CSI；复用同一次分解得到的子空间，计算全局粗谱和峰附近的局部谱 |
| 采样 | `estimate_music_peak_samples` 或 `estimate_batched_peak_samples` | 新增谱面采样函数，直接输出每个峰的角度、观测时延样本；每个样本记录来源峰编号和独立样本编号 |
| 峰身份 | `associate_perturbed_peaks` 在各次重提峰之间配对 | 在采样时继承来源峰编号，移除扰动峰配对步骤；这不代表真实物理路径身份已知 |
| 观测样本组织 | `_build_observation_samples` 分成原始峰和各次扰动两组 | 组织成按来源峰分组的谱面样本集合，再合并为反向追踪的完整输入 |
| 反向追踪 | `generate_reverse_candidates` 主调用只接收 `nominal_samples` | 主调用接收全部谱面样本，输出完整候选集合，并保留每个候选的来源及有效 bias 区间 |
| 第一次聚类 | 每个原始峰单独反推后聚类；代表轨迹采用平均参数 | 汇集该来源峰的全部候选后，按反射结构分组聚类；选有效成员作代表，限制簇内轨迹差异，避免仅因局部接近而合并 |
| 联合求解 | 中心解，以及 `_bootstrap_joint_solutions` 的各次独立解 | 将第一次聚类的代表候选直接交给共同 bias 与位置求解器；同一路径的候选互为替代 |
| 最终结果 | `_distribution_statistics` 汇总各次扰动解的位置与 bias | 输出这一份观测对应的联合求解结果及诊断；移除扰动解平均与扰动解协方差汇总 |

原始谱峰可以保留为谱图标记，并作为各自候选集合中的一个确定参考样本；它们不再单独形成一条定位分支。

现有 `solver.py` 的共同 bias 参数和候选选择机制可以复用。候选数量增加后，需要检查求解规模、计算预算，以及失败或多解状态的输出。几何残差得到的近似协方差若继续保存，必须标明计算来源，不能称为谱面采样得到的置信区间。

### 6.3 计算方式和配置同步调整

- 将“CSI 的协方差与子空间计算”和“给定角度、时延坐标的谱值计算”拆开，同一份观测只做一次分解。
- GPU 批量处理局部谱值和角度、时延样本；反向追踪可按样本分批并行。是否更快以实际计时为准。
- 主配置移除重复加噪次数、额外噪声强度、扰动峰配对等参数；新增每峰采样数、角度和时延采样范围、局部谱细化设置、均匀采样比例、随机种子及批量大小。
- 记录采样分布和簇内样本数量，但不把采样数量直接当成观测精度或独立测量次数。若按谱值抽样，也不能未经推导再用同一谱值重复加权。
- 同步更新配置校验、结果格式、文件清单和报告读取逻辑，避免报告继续要求已经删除的扰动文件。
- 实现固定后，同步更新 `.sh` 入口，在固定参数区明确实验配置、样本数量、输入、输出和 GPU 设置，并检查旧参数能否明确报错，防止悄悄运行旧分支。

### 6.4 每个 sample 的中间输出同步改名和改内容

保留每个 UE 一个文件夹、每份模拟接收数据一个 `repeat_XXX` 子文件夹的组织方式，实际目录为：

| 阶段 | 内容 |
| --- | --- |
| `00_scene_truth` | 场景、BS、真实 UE 与真实路径，仅用于独立评估和示意图 |
| `01_csi_input` | 接收 CSI 与公开定位配置 |
| `02_music` | 这份带噪 CSI 的 MUSIC 谱与谱峰表 |
| `03_spectrum_sampling` | 各峰的采样区域、局部谱、采样散点及角度和时延表 |
| `04_reverse_candidates` | 全部采样点反推的候选、有效 bias 范围及来源编号 |
| `05_first_clustering` | 簇成员、代表候选、聚类前后数量和叠加图 |
| `06_joint_solution` | 选中的代表候选、估计位置、共同 bias、残差与求解状态 |
| `07_forward_check` | 将估计结果正向计算得到的路径特征与接收观测比较；检查不使用真实位置或真实 bias |
| `08_final_evaluation` | 最终估计、真实值、位置欧式误差与 bias 误差，由独立评估阶段生成 |

总体汇总使用各份接收数据的最终结果，输出定位误差中位数、P90、CDF、bias 误差和失败率，并写清成功数量与总尝试数量。中途失败也应保存已完成的步骤和失败原因。

新结果需要写入独立输出目录并标明流程版本；旧实验和旧报告保留，不能仅靠重画旧结果来冒充新流程的输出。
