# 统一细谱与 DBSCAN 点聚类

更新日期：2026-09-09。流程标识：`music_fine_spectrum_dbscan_v3`，定位清单版本为 6。

## 本次修正

旧 v2 把初始点分成多个最大跨度不超过 1.5 米的小簇，因此 UE001 图上的三个完整点团被切成了 16 簇。
新流程用 DBSCAN 识别密度相连的点团。1.5 米表示邻近范围，整个簇的跨度可以超过这个距离。
每簇只选一个真实成员代表，之后才为代表建立随公共偏差变化的位置轨迹。

另一个修正是正式峰、采样概率和局部谱图全部使用同一份细谱：

```text
一份带噪 CSI
  → 一次协方差与特征分解
  → 粗 MUSIC 谱确定搜索区域
  → 局部细谱重新找正式峰、按实际角度和时延间距去重
  → 同一细谱生成采样概率、连续采样角度与观测时延
  → 参考 bias 下反向 RT 得到初始位置点
  → DBSCAN 点聚类，每簇一个真实成员代表，单独记录离群点
  → 只为代表建立轨迹
  → 一次位置与公共 bias 联合求解
  → 使用正式细峰做正向检查
  → 独立读取真值评估
```

定位不再给 CSI 额外加噪。每个 UE 的 5 次独立噪声重复仍属于实验数据生成。
真值不参与找峰、采样、聚类、参数选择或联合求解。

## 细谱的统一规则

- 当前 Munich 粗网格步长为 1°、1 ns。粗峰只确定待检查的区域，不再作为正式观测。
- 每个区域通常覆盖粗峰两侧各 1.5 个粗网格，用 25×25 个节点计算局部细谱，通常步长为 0.125°、0.125 ns。
- 正式峰是该细谱最大值所在的节点；谱图中的星号、额外参考样本和正向检查使用这个峰。
- 每个采样单元的谱值由该单元四个角的细谱值取平均得到，不再独立重算一套中心谱。
  单元概率与该均值的 `spectrum_power` 次方乘单元面积成正比，再混入 `uniform_mixture` 比例的均匀采样。
- 选中单元后在单元内均匀生成连续坐标。连续坐标的精确谱值只作诊断，不再次参与概率或求解权重。
- `num_paths` 继续作为粗搜索候选峰上限。细化后按物理角度、时延间距去重，可能得到更少正式峰；不足两峰时明确失败。
- 去重后保留原来源编号，不把后续峰重新编号。`music_peaks.json` 的 `nominal_source_indices` 与正式峰逐项对应。
- 如果最大值位于人为窗口边缘，记录 `unresolved_window_peak=true`；它仍是本窗口的最大值，但不能据此声称窗口外没有更高峰。
  本次三份重放数据均未出现这种情况。

这里的采样概率用于候选搜索，没有被校准为路径后验概率或定位置信区间。

## DBSCAN 的具体约定

配置位于定位 YAML 或实验的 generation_config 中：

```yaml
localization:
  initial_reference_bias_s: 0.0
  candidate_cluster_radius_m: 1.5  # DBSCAN eps，邻域距离，单位米
  candidate_cluster_min_samples: 5  # 邻域点数，包含点自身
```

保留 `candidate_cluster_radius_m` 名称以兼容配置，v3 中它不再表示簇的最大跨度。
默认 1.5 米、5 点是本次确认的初始设置；改变每峰采样数会影响密度，不能假定参数与采样数无关。

1. 不同来源峰、不同完整反射墙面顺序分别聚类，不能因为位置靠近就把不同物理解释混在一起。
2. 使用初始参考位置的二维欧式距离。邻域内至少有 5 个点的是核心点，邻近核心点连接成簇。
3. 非核心点若邻近核心点，作为该簇的边界成员；邻近多个簇时按最近核心点分配，同距按稳定样本顺序决定。
   边界点不能把两个核心点簇连接起来。
4. 其余点作为离群点单独记录。它们不生成代表或轨迹；“离群”只是当前密度规则的判断，不证明该物理路径不存在。
5. 每簇选使簇内加权距离总和最小的一个实际成员，保留该成员的反射路径和时延。密度计算只计等权样本数，不使用谱值。

聚类发生在轨迹建立之前。不固定簇数为 3；例如 UE010 的同一来源峰可以有不同反射墙面顺序，仍应保留多个代表。
公开参考 bias 只用于生成聚类点，最终 bias 仍由联合求解估计。

## 可直接运行的脚本

重放已有 CSI，默认检查 UE001、UE010、UE006，各一次；只读原数据，写入新的结果目录：

```bash
cd /data/zhujun/differt_projects/time-bias-correct
./run_fine_dbscan_check.sh
```

脚本顶部集中设置 `SOURCE_EXPERIMENT`、`CONFIG_PATH`、`OUTPUT_ROOT`、`UE_IDS`、`SAMPLES_PER_PEAK`、
`DBSCAN_EPS_M`、`DBSCAN_MIN_SAMPLES` 和设备。默认使用项目 `.sionna-venv/bin/python` 与 GPU 0。
CPU 检查可设置 `COMPUTE_BACKEND=numpy`。已有输出目录会被拒绝，不会覆盖旧结果。

全量新实验，默认 1 BS、30 UE、每 UE 5 份独立噪声：

```bash
cd /data/zhujun/differt_projects/time-bias-correct
GPU_IDS=0,1,2,3,4,5,6,7 PLAN_ONLY=0 RESUME=0 ./run_fine_dbscan_experiment.sh
```

该脚本的参数区配置输入实验 YAML、输出根目录、设备与执行开关。
UE 数量和噪声次数在 `configs/visualization_experiment_munich.yaml`；BS、MUSIC 和 DBSCAN 参数在其引用的 generation_config。
`PLAN_ONLY=1` 只核对输入并生成计划，不执行信道生成或定位。
旧版计划不能用 `RESUME=1` 混入 v3 结果；旧入口脚本也执行当前代码，不能用旧脚本名复现旧算法。

## 每步输出

每个样本仍有独立的 `samples/UE编号/repeat_编号` 目录，保存 00–09 的实际步骤。

| 步骤 | 新的可检查内容 |
|---|---|
| 02_music | 粗搜索谱、粗搜索点表、正式细峰表及来源编号 |
| 03_spectrum_sampling | 同一细谱上的正式峰和连续采样点；新增实际单元采样概率图；粗细位置与边界诊断 |
| 04_initial_candidates | 反向 RT 初始点及排除原因 |
| 05_point_clustering | 簇成员、每簇唯一代表；灰叉表示离群点；逐点归属 CSV 和聚类参数/计数 |
| 06_representative_trajectories | 只由代表点建立的轨迹 |
| 07–09 | 联合解、基于正式细峰的正向检查、独立误差评估 |

离群点保存在 `noise_points.json/csv`，逐点角色保存在 `point_memberships.csv`。
报告核验簇成员与离群点完整覆盖所有初始点，失败样本仍保留完成的步骤。
总体 `summary` 继续输出定位误差 CDF、Med、P90 和失败/待运行计数。
旧 v2、v1 与更早结果按原流程解释，不改写旧实验产物。
